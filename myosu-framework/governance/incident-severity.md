# Incident Severity Matrix

| Severity | Definition | Response |
|----------|-----------|----------|
| **S1** | Published provenance failure, unauthorized external action, dual-use exposure, uninterruptible compositional chain | Immediate containment, root cause analysis, governance review, public correction if published |
| **S2** | Firebreak breach, agent synthesis entering /my-thinking/ without promotion, threshold marker stripped, circular synthesis undetected | Quarantine affected notes, freeze agent role, governance review |
| **S3** | Missing provenance metadata, retrieval bias detected, review overload, epistemic marker missing | Flag for review, adjust thresholds, no freeze required |
| **S4** | Documentation gap, minor process deviation, overdue review | Document and schedule remediation |

## Escalation

- S1: Immediate. Notify governance review. Pause publication pipeline.
- S2: Within 24 hours. Review and remediate.
- S3: Within weekly cadence. Address in next governance review.
- S4: Within monthly cadence.
