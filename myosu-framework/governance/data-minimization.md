# Data Minimization

## External Data

- Research subject personal data: minimize retention. Anonymize where possible.
  Delete raw data after anonymization unless consent permits retention.
- Interview transcripts: store with access controls. Delete when project
  completes unless explicit consent for long-term retention.
- Source metadata: retain only what is necessary for provenance.

## Internal Data (John's Own Thoughts)

- Provisional thoughts (epistemic_status=working_idea): excluded from agent
  retrieval by default. Accessible via direct lookup only.
- Abandoned ideas (epistemic_status=abandoned): excluded from all agent
  retrieval. Retained for intellectual history only.
- Governance logs: must not retain sensitive personal data beyond what is
  necessary for governance purposes.
- Interaction profile: if implemented, must be inspectable and resettable
  by John. Must not be used for purposes beyond vault operation.

## Retention Limits

- Working ideas: retained indefinitely but excluded from retrieval
- Abandoned content: reviewed annually for potential deletion
- Governance logs: retained for duration of system operation + 1 year
- Source cache: retained while project is active
