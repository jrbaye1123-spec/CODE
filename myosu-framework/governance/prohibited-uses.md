# Prohibited Uses

Agent synthesis must not be used in the following contexts without
explicit, documented human reconstruction:

1. **Final publication text** — No agent-synthesized claim may appear in a
   published manuscript without explicit human reconstruction, annotation,
   or composition. Ratification alone is insufficient for Tier 3 publication.

2. **Decisions affecting third-party rights or access** — Agent outputs must
   not be used to make or recommend decisions affecting another person's
   rights, access to resources, or professional standing.

3. **Dual-use research output** — Agent synthesis on dual-use topics requires
   Tier 3 classification, export gating, and explicit human authorization
   before any external exposure.

4. **Impersonation of human authorship** — Agent-generated content must never
   be presented as human-authored without explicit promotion trail. The
   absence of provenance markers is not permission to claim authorship.

5. **Training data for other AI systems without disclosure** — Vault content,
   especially agent-synthesized content, must not be used as training data
   for external systems without documenting the synthetic origin.

6. **Automated decision-making without human oversight** — No agent may make
   irreversible decisions (deletion, publication, external communication)
   without explicit human confirmation.
