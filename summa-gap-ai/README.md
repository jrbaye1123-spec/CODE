# Summa-Gap AI

## The Complete Architecture of the Vault — Operationalized as a Foundation Model

This project fine-tunes a foundation model on the *Summa of the Gap* framework (1,440 pages, 30 books, 6 volumes) using QLoRA. The resulting model is:

- **Framework-native**: Understands the logdet probe, Lawvere gap, five zeros, spectral bridge, and engine diagram as first-class reasoning primitives.
- **Quantum-proof**: Deployed with Kyber-1024 (post-quantum KEM), Dilithium-5 (post-quantum signatures), and SHA-512 integrity verification.
- **Self-evaluating**: Ships with the Summa's own logdet probe for representational health monitoring.
- **Science-ready**: Trained for cross-domain reasoning across physics, computation, consciousness, and cybernetics.

## Quick Start

```bash
# 1. Install dependencies
pip install -r requirements.txt

# 2. Prepare training data from the Summa corpus
python3 scripts/prepare_data.py

# 3. Fine-tune with QLoRA (requires GPU)
python3 scripts/train_qlora.py \
    --model_name meta-llama/Llama-3.1-8B-Instruct \
    --data_path data/summa_training_data.jsonl \
    --output_dir models/summa-gap-8b-qlora \
    --epochs 3

# 4. Evaluate with the logdet probe
python3 eval/logdet_probe.py --model_path models/summa-gap-8b-qlora/final

# 5. Start quantum-proof inference server
python3 deploy/quantum_proof_wrapper.py --model_path models/summa-gap-8b-qlora/final
```
