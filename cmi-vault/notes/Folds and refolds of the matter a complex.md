# Folds and Refolds of the Matter

**Bridge to CMI**: Folding structures (origami engineering, crumpling, kirigami) create geometric complexity that maps naturally to CMI's state manifold. The "folds" are singularities in the material's geometric description — places where the embedding into 3D space fails to be smooth. In CMI, these correspond to regions of high ∇self curvature where degradation accelerates. The refolding suggests topological transitions — changes in the state manifold's genus that alter the Noether charge.
